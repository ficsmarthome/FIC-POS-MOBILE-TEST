# FIC POS Mobile V1.13.30 - Purchase Return Detail

- Trả hàng nhập list now shows return code, amount, supplier, purchase code and date.
- Tap a return slip to open a dedicated detail screen.
- Detail shows supplier, source purchase, reason, creator, returned products, quantities, unit prices and totals.
- Includes purchase reconciliation: original value, returned value, remaining value, paid amount, supplier debt, supplier credit/refund received/refund due.
- Keeps existing lazy-load pagination.
