# FIC POS Mobile V1.13.32+86 — Money & Sale Shift Gate

Android/iOS dùng chung source.

- Thêm gate dùng chung cho thao tác phát sinh tiền.
- Trả hàng bán/hoàn tiền: bắt mở ca tại lúc thao tác, xem danh sách không cần ca.
- Nhận tiền NCC hoàn: bắt mở ca.
- Tạo phiếu nhập: chỉ bắt ca nếu có thanh toán ban đầu > 0.
- Sổ thu chi: xem được khi chưa mở ca; tạo phiếu thu/chi mới bắt ca.
- Order/bán hàng tiếp tục dùng shift gate hiện có.
- Sau mở ca quay lại đúng thao tác/màn hình.
- Server V255.50 tiếp tục là lớp bảo vệ cuối cho API tài chính.
