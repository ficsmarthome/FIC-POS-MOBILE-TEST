# FIC POS MOBILE FINAL BASELINE

- Version: **1.13.32+86**
- One Flutter codebase for Android and iOS.
- Includes online/offline order workflow, sync, branch-aware notifications, recipes, purchase/returns, cashbook, shift gating and operational modules.
- Build outputs, local Gradle/Dart caches, signing files and Firebase production credentials are intentionally excluded.
- Run `flutter pub get`, configure platform credentials/signing, then build Android/iOS.
- Canonical architecture and build notes are in the FINAL MASTER documentation bundle.
